## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
An MCP client holding an API key can initialize, list tools and call them over Streamable HTTP at /mcp, using the MCP server that ships with Effect 4 (no new dependency). One tool per typed operation, named by operationId, input schema from its Schema. See NOT-169.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 initialize, tools/list and tools/call work over HTTP with a Bearer API key; no key or a cookie session is refused
- [ ] #2 A read key lists only read tools, and calling a write tool with it is refused
- [ ] #3 Malformed tool arguments are a validation error naming the field
- [ ] #4 A tool result equals the REST response for the same operation
- [ ] #5 A page the key owner cannot read is not readable through MCP
<!-- AC:END -->
